# Phase 5.6 — Multilingual SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move SEO fields onto the translation sidecar (per-locale) via a `SeoTranslation` base, retire the parent-side `ISeoMeta`, and resolve a per-locale OG image into its `File` object on read.

**Architecture:** SEO becomes translatable: a Domain `SeoTranslation` abstract base (carrying `[CmsField]`, a Domain attribute) supplies `SeoTitle`/`SeoMetaDescription`/`SeoOgImageId`; translation sidecars inherit it and the scanner's existing inherited-property scan marks them translatable. `ISeoMeta` (parent SEO) is removed. The translation overlay (`ItemService.OverlayTranslationsAsync`) is extended to eagerly resolve `Image`-typed translatable fields into the referenced `File` (batch-loaded), nesting it per locale.

**Tech Stack:** .NET 10 / C# latest · SqlSugarCore (PostgreSQL default, SQLite in tests) · xUnit + AwesomeAssertions.

## Global Constraints

- Dependency rule (§2): Domain references nothing external — **`[SugarColumn]`/SqlSugar never in Domain**, but `[CmsField]` IS a Domain attribute and is allowed there. Application → Domain only; Infrastructure → Application+Domain; framework (`src/*`) never references `samples/*`.
- SEO is declared **only** on the translation sidecar (single path); `ISeoMeta` is removed.
- `OnDelete` for `SetNull`/`Cascade` stays **unenforced** (deferred) — a dangling image id resolves to `null`, never throws.
- Editable/queryable locales are bounded to enabled languages (`languages.IsEnabled`) — already enforced; no change.
- All DB access via SqlSugar; `InitTables` dev-only; outbound JSON camelCase; `dotnet build` warnings-as-errors; solution compiles after every task.
- TDD: failing test first; live-Postgres gate is mandatory before "done" (Task 3).

- [ ] **Step 3: Extend `OverlayTranslationsAsync` to resolve image fields**

In `src/Struo.Application/Query/ItemService.cs`, after the `grouped` map is built and the per-locale field maps are assembled, add resolution. Insert this logic operating on the `grouped` (parentKey → locale → fieldMap) maps before attaching them to rows:

```csharp
// --- per-locale image resolution (Phase 5.6) ---
// Translatable fields that reference the file collection (convention: Image/File/Files interfaces).
var imageFields = meta.Fields
    .Where(f => f.Translatable && f.Interface is FieldInterface.Image or FieldInterface.File or FieldInterface.Files)
    .Select(f => f.Name)
    .ToList();

if (imageFields.Count > 0)
{
    // Collect distinct non-null Guid ids across every locale field map.
    var imageIds = grouped.Values
        .SelectMany(byLocale => byLocale.Values)
        .SelectMany(fieldMap => imageFields
            .Where(fn => fieldMap.TryGetValue(fn, out var v) && v is Guid)
            .Select(fn => (object)(Guid)fieldMap[fn]!))
        .Distinct()
        .ToList();

    var byId = new Dictionary<Guid, IReadOnlyDictionary<string, object?>>();
    if (imageIds.Count > 0)
    {
        var files = await repository.QueryWhereInAsync("file", "id", imageIds, ct);
        foreach (var f in files)
        {
            var projected = ProjectFor("file", f, null);
            if (projected.TryGetValue("id", out var idVal) && idVal is Guid g)
                byId[g] = projected;
        }
    }

    // Inject the resolved object beside the raw id in every locale field map.
    foreach (var byLocale in grouped.Values)
        foreach (var fieldMap in byLocale.Values)
            foreach (var fn in imageFields)
            {
                if (!fieldMap.TryGetValue(fn, out var raw) || raw is not Guid g) continue;
                var resolvedKey = fn.EndsWith("Id", StringComparison.Ordinal) ? fn[..^2] : fn + "Resolved";
                fieldMap[resolvedKey] = byId.TryGetValue(g, out var file) ? (object?)file : null;
            }
}
```

Notes for the implementer:
- `FieldInterface` lives in `Struo.Domain.Metadata.Enums` — add the `using` if missing.
- The `fieldMap` values inside `grouped` are built as `new Dictionary<string, object?>()` in the existing code, so adding the resolved key is fine. Keep the concrete `Dictionary<string,object?>` reference used at build time (don't downcast to `IReadOnlyDictionary` before this runs).
- This runs once per overlay call: a single `QueryWhereInAsync` batch regardless of locale/row count (no N+1).
