# StruoCMS Documentation

This manual documents the StruoCMS template itself — the framework, its configuration, and how to
extend it. It is written in two languages, chapter-for-chapter, with the same chapters in the same
order in both. For the one-page overview, quick start and license, see the project
[`README.md`](../README.md).

## Reading this manual in a browser

The chapters render as a searchable site with a sidebar and a light/dark toggle. The site is its own
project, so it installs separately from the admin SPA:

```bash
pnpm -C docs install
pnpm -C docs dev
```
